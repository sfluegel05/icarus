Tutorial: learn a chemical rule from examples

ICaRuS learns a Prolog rule for a chemical concept (for example "carboxylic acid") from molecules you label as positive or negative. You start from a ChEBI class or from SMILES / InChI strings, let ICaRuS suggest more molecules, learn a rule with an ILP system, and then inspect, edit and compare the rules. This tutorial walks through one complete session on the web page at /.

Each browser tab has its own session. Everything below was done in one tab, using the Popper method. Your results will differ slightly, because the suggestions and the learned rule depend on the examples.

1 · Seed the examples from a ChEBI class

Type at least two letters into Seed from a ChEBI class, for example carboxylic acid. Pick a class from the list; the selected class and its molecule count are shown below the field. Set how many positive and negative molecules to take (default 8 each) and click Fill examples.

The positives are small molecules below the class in ChEBI, and the negatives are molecules close to the class in the hierarchy that are not part of it. Only concrete molecules are used; generic class structures with wildcard atoms are skipped.

2 · Sort and add examples

Each molecule card shows its 2D structure. Click a card to open its details: a zoomable structure, the ChEBI ID, SMILES, InChI and definition. In the details you can move the molecule to the other column or remove it. Close the dialog with ×, Esc or by clicking outside it.

The small buttons on a card do the same without opening the dialog: → − or → + moves it, and × removes it. You can also drag a card into the other column.

To add your own molecules, paste SMILES or InChI into the text box of a column, one per line, and click Add + (positive) or Add − (negative). Here two negatives (ethanol and ethyl acetate, which are not acids) were added.

3 · Label suggested molecules

If you need more examples, click Find similar molecules. ICaRuS looks for ChEBI molecules similar to your positives (Morgan fingerprints) and shows them one at a time. Each card shows the similarity score, the structure, the name, the ChEBI ID and the definition.

Use ← + Positive or − Negative → to label the current molecule, or Skip to pass on it. The counter (for example 3 / 6) shows your position in the batch. Once a rule exists, each card also shows what the rule predicts, so you can confirm or contradict it.

In this session the first suggestion was labelled positive and the second negative. The counts in the example grids were updated after each choice.

4 · Learn a rule and read the result

In Learn a rule, choose a method and click Learn rule. The method dropdown offers Popper (ILP) and Aleph (ILP), both of which run on the ICaRuS server; the timeout (default 60 seconds) limits the ILP search. The LLM option sends the concept to an external model and is not used in this tutorial.

While the learner runs, its output streams into the output panel. show full output shows the complete log. When the run finishes, the rule appears below, with a result summary.

The result shows:

  • Build the rule — the rule as blocks (the molecule-level property, and atoms with their bonds).
  • In words — a natural-language translation of the rule.
  • The confusion counts (TP, TN, FP, FN) and the list of molecules not classified as told. A false positive (FP) is a negative example the rule marks positive; a false negative (FN) is the reverse. A molecule that the rule marks positive has a ? button on its card.

Click ? on a positive molecule to see why the rule accepts it. The explanation highlights the responsible atoms and lists the facts that match.

5 · Edit the rule and apply it

You can change the rule in two ways. Drag blocks from the palette onto the molecule or an atom in the Rule canvas, or open Advanced: edit as Prolog and edit the text directly. Edited Prolog is parsed back into blocks when you click away.

In this session the rule was one literal, so the edit appended a condition: the molecule must also contain a nitrogen atom. Click Apply edited rule to run the edited rule. Its result becomes a new entry in the history, and ICaRuS lists every classification that changed.

Revert edits discards unsaved changes and restores the selected rule.

6 · Add examples and learn again

A rule is only as good as its examples. Use the steps above to improve them: add SMILES, move molecules between the columns, remove doubtful ones, or label more suggestions. In our run, the rule marked glyoxylate as positive although it was labelled negative; relabelling it or leaving it as the one error are both valid decisions, depending on your concept.

In this session acrylic acid (positive) and hexane (negative) were added, and then Learn rule was clicked again. Each learning run adds a new entry to the history and makes it the selected rule. The result depends on the examples, so the learner can return a different rule than before.

7 · Compare rules in the history

Every learned or edited rule is kept. Click ▸ Show rule history (n) to list them, newest first. Each entry shows its origin (POPPER or EDITED), its age, the rule, and its confusion counts. The selected rule is marked ● selected.

Click Select on another entry to make it the current, editable rule. Selecting does not learn anything new. When the examples change, an entry is marked ⚠ examples changed since — re-evaluate, because its counts refer to the old examples. The Re-evaluate all button then recomputes all counts against the current examples.
